# 试卷转互动讲评网页（exam-review-web）

把一份试卷（Word / PDF / 扫描图片 / 纯文本）变成一个**可离线打开、全学科适用**的互动讲评网页（单文件 HTML）。

## 三步使用

1. **触发**：在 WorkBuddy 对话中说"把这份试卷做成互动讲评网页"，并附上试卷（文件或文本）。
2. **配色**：AI 第一件事会问你要哪种配色（中国红 / 活力橙 / 清新绿 / 静谧蓝，或自定义）——这是铁律，不替你决定。
3. **产出**：AI 按"读取原卷 → 重建结构 → 补足讲评+引导 → 教学增强 → 加入交互 → 验证交付"生成 **讲评.html**，双击即开、不联网、不装插件，U 盘拷到教室电脑就能上。

## 内置功能

- 结构：左侧悬停大纲、上一题/下一题导航
- 课堂工具：🔍放大镜（滚轮调倍数）、🎲随机点名、✏️批注、⏰计时器、🖥️全屏
- 🧭 引导：苏格拉底式分步问答，选错指路不放行，走完给具体夸赞+方法小结
- 📖 讲评：八要素深度分析（考点/设坑/易错/补救/解题步骤/原文定位/关键词/排除干扰）
- 英语专属：词汇点击弹窗、逐句点译、听力播放器（音频 base64 内嵌）

## 直接改数据也能用

打开 `templates/exam-review.html` 即可看示例效果。把它复制成你的文件，只改顶部 `EXAM_DATA` 那一块（题目、讲评、引导、词汇等），其余代码不用动。所有资源（音频/图片）用 base64 内嵌，保证单文件、零外链、离线可用。

## 文件结构

```
exam-review-web/
├─ SKILL.md                      # 技能主指令（六步流程 + 两条铁律）
├─ README.md                     # 本文件
├─ references/
│  ├─ methodology.md             # 四篇文章方法论汇编
│  └─ prompt-templates.md        # 提取/讲评/引导/英语增强 提示词
└─ templates/
   └─ exam-review.html           # 单文件引擎（含可运行示例）
```
