# 提示词模板 · 试卷转互动讲评网页

> 本文件给"试卷转互动讲评网页"技能配套使用。Agent 在六步流程的不同阶段，复制对应提示词、填入用户提供的试卷内容即可。
> 原则：所有解析/引导/词汇均由 AI 基于原卷生成，**不编造与原卷无关的内容**；凡涉及"学生学情"的判断，保留给用户最终拍板。

---

## 模板 A · 原卷结构化提取（第1–2步）

```
你是一名严谨的试卷结构化助手。请阅读下面这份【{学科}·{学段}】试卷原文，
输出严格的 JSON 数组，每个元素是一道题：

{
  "id": "q1",
  "section": "阅读理解",          // 题型/板块，如 听力/阅读/完形/语法/写作/计算
  "stem": "题干原文（保留原句，勿改写）",
  "options": ["A. ...","B. ...","C. ..."],  // 无选项题型(如写作)留空数组
  "answer": "C",                 // 标准答案
  "passage": "（阅读/完形等的原文，没有则省略）"
}

要求：
1. 按试卷原有顺序编号，题型相同的归到同一 section。
2. 不丢题、不并题、不改答案。
3. 扫描件已转文字，直接处理文本。
4. 只输出 JSON，不要解释。
```

---

## 模板 B · 八要素讲评生成（第3步）

```
基于上面第 q{N} 题（题干：{stem}；答案：{answer}；原文：{passage}），
请以【{学科}】教师的视角，生成"八要素讲评"，严格按如下字段输出：

- 考点：这题实际考查的知识点/能力
- 设坑：命题人设置的干扰或陷阱
- 易错：学生最可能在哪一步栽
- 补救：做错后应如何补漏/纠正
- 解题步骤：3–5 步可操作的解题链（编号列表）
- 原文定位：回原卷的证据句/条件（英语阅读必须给原文出处）
- 关键词：锁定答案的词眼
- 排除干扰：逐条说明其他选项为什么错

要求：语言口语化、面向中学生，不堆术语；每条 1–3 句。
```

## 模板 C · 苏格拉底「引导」生成（第3步，铁律：每题必写）

```
针对第 q{N} 题，请设计一个"苏格拉底式引导"脚本，带学生自己走通思路。
输出 JSON 数组，2–4 步，每步结构：

{
  "prompt": "第一步问什么（如：这道题真正问的是？）",
  "options": ["选项1","选项2","选项3"],   // 2–4 个
  "correctIndex": 1,                        // 正确选项下标(0起)
  "wrongHint": "选错时的反馈：说明为什么这个思路偏了、该往哪想",
  "rightHint": "选对时的反馈：肯定具体行为，并引出下一步"
}
// 最后一步的 rightHint 改为：走完后的【一句具体夸赞 + 方法小结】

铁律：
- 夸具体行为，不夸天赋。❌"你真聪明" → ✅"你注意到…很多人会栽在这里"
- 每步选项须有迷惑性，不能一眼看出答案
- wrongHint 要"指路"而非"揭答案"
```

## 模板 D · 英语专属增强（第4步，仅英语/含阅读题型）

### D1 词汇弹窗
```
从下面这篇英语原文中提取 6–12 个重点词汇，输出 JSON 数组：
{ "word":"destination", "pos":"n.", "meaning":"目的地",
  "root":"de- + stin(站立/设定)",
  "collocation":"tourist destination / final destination",
  "example":"...含该词的例句...", "exam":"高频考法/辨析" }
要求：词在原文中出现；释义准确；词根词缀真实。
```

### D2 逐句点译
```
将下面英语段落按"句子"切分，输出 JSON 数组：
{ "en":"原句英文", "zh":"该句中文（信达雅，不整段堆砌）" }
要求：一句一译，便于网页"点哪句译哪句"。
```

### D3 听力
```
对听力每题：提供该题音频。若只有整段录音，请按题切分并转为 base64 内嵌。
网页侧每题独立播放器，支持 循环 / 0.75 倍速。
（无音频资源时，跳过此模块，不要留空播放器）
```

---

## 模板 E · 验证交付清单（第6步，破坏式验证）

生成 HTML 后，逐项核对：
- [ ] 双击 HTML 能开，断网也能开（无外链、无 CDN 依赖）
- [ ] 所有音频/图片已 base64 内嵌，无 404
- [ ] 故意点错「引导」选项 → 出现 wrongHint 且不放行
- [ ] 点对「引导」→ 进入下一步，走完有夸赞小结
- [ ] 「讲评」八要素每题齐全
- [ ] 大纲跳转、上一题/下一题、全屏、计时器、点名、批注、放大镜均可用
- [ ] 英语卷：词汇弹窗、逐句点译、听力播放器正常
- [ ] 换一台电脑（或 U 盘拷贝）打开仍正常
```
